# Radarium — краткое описание продукта

> Документ для руководителя организации.  
> Актуально на: **июнь 2026**

---

## Что такое Radarium

**Radarium** — это онлайн-сервис для поиска исполнителей и подрядчиков в строительной и проектной отраслях.

Продукт собирает объявления из профессиональных сообществ в **Telegram** и **ВКонтакте** (более 100 источников), автоматически разбирает их и превращает в удобный каталог: кто предлагает услуги, кто ищет работу, кто нанимает. Пользователь находит нужного специалиста за минуты вместо ручного просмотра десятков чатов.

---

## Какую задачу решает

| Было | С Radarium |
|------|------------|
| Менеджер вручную мониторит чаты и группы | Система сама собирает новые объявления |
| Информация разрознена и быстро теряется | Единый каталог с поиском и фильтрами |
| Сложно понять, подходит ли человек по специализации и региону | Карточки с профилем, специализацией, регионом |
| Контакты «находятся с трудом» | Контакты доступны по тарифу — быстро и централизованно |

**Суть:** Radarium экономит время и снижает зависимость от ручного поиска кадров и подрядчиков в открытых источниках.

## Для кого продукт

**Основные клиенты (пользователи сервиса):**
- компании, которым нужны строители, бригады, подрядчики;
- организации, ищущие проектировщиков и смежных специалистов;
- HR и закупки, которым важна скорость подбора.

**Внутренние пользователи (сотрудники организации-владельца):**
- администраторы — управление каталогом, модерация, настройки;
- аналитики — отчёты по активным авторам и качеству базы.

## Как устроен продукт (простыми словами)

```
Открытые группы и каналы  →  Автоматический сбор  →  Разбор объявлений  →  Каталог  →  Поиск и контакты
   (Telegram, VK)              (регулярно)            (искусственный          (сайт)      (по подписке)
                                                         интеллект)
```

1. **Сбор** — сервис регулярно читает новые сообщения из подключённых групп и каналов.
2. **Разбор** — система определяет тип объявления: предложение услуги, резюме, вакансия, «шум» (реклама, найм не по теме и т.п.).
3. **Каталог** — подходящие объявления попадают в структурированные карточки с фильтрами по специализации, региону, ключевым словам.
4. **Доступ** — зарегистрированный пользователь ищет исполнителя и получает контакт по тарифному плану.
5. **Контроль качества** — сомнительные карточки отправляются на модерацию; есть отзывы и рейтинги.

| **Строительство** | Бригады, мастера, подрядчики по видам работ |

## Монетизация

Radarium — **коммерческий продукт** с платным доступом к контактам:

- тарифные планы с лимитом на число открытых контактов;
- оплата через платёжный сервис (Robokassa);
- личный кабинет: подписки, история платежей, остаток контактов.

Бесплатно пользователь может просматривать каталог; контактные данные открываются после оплаты тарифа.

---

## Качество данных и доверие

Чтобы в каталог не попадал «мусор» из чатов, в продукте заложено несколько уровней контроля:

- **Автоматический отбор** — объявления о найме персонала, подработках и нерелевантные сообщения отсекаются до публикации.
- **Модерация** — спорные карточки проверяет администратор; пользователь может пожаловаться на запись.
- **Отзывы** — после работы с исполнителем можно оставить оценку.
- **Актуальность** — в выдаче учитываются только обработанные и подтверждённые записи.

---

## Конкурентные преимущества

1. **Охват источников** — десятки профильных Telegram-каналов и групп VK в одном месте.
2. **Скорость** — новые объявления обрабатываются автоматически, без участия оператора.
3. **Точность** — специализации и регионы приводятся к единому справочнику; поиск по отрасли, а не только по словам в тексте.
4. **Экономия** — меньше затрат на ручной мониторинг чатов и посредников.

## Текущее состояние продукта (2026)

**Работает и используется:**
- сбор из Telegram и VK;
- каталог строителей, проектировщиков и вакансий;
- поиск, фильтры, тарифы, оплата, личный кабинет;
- админ-панель: модерация, отчёты, настройки источников;
- система отзывов.

**Недавние улучшения:**
- расширен контроль качества (отсечение найма и нерелевантных объявлений);
- подключены группы VK как дополнительный источник;
- доработаны регионы и справочник специализаций для строительства;
- отчёт по активным авторам для контроля базы.

## Что важно знать руководителю

| Вопрос | Ответ |
|--------|-------|
| Это готовый продукт или «проект в разработке»? | **Рабочий продукт** с платными функциями и регулярным наполнением базы |
| Нужны ли постоянные «ручные» операции? | Минимально: модерация спорных случаев и настройка источников |
| Зависит ли от одного канала? | Нет, источников много; добавление новых групп расширяет охват |
| Есть ли риски по данным? | Используются только **открытые** публикации из групп и каналов |
| Как оценить эффективность? | Отчёты по авторам, конверсия тарифов, качество модерации, рост каталога |
