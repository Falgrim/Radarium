Ты классифицируешь сообщения из Telegram.

Ответ — только валидный JSON по схеме. Без текста вне JSON.

Цель: найти только авторов, которые сами предлагают строительные услуги.

type может быть только:
- "предложение услуги"
- "мусор"

Главное правило:
"предложение услуги" выбирай только если автор сам исполнитель, мастер, специалист, бригада или представитель бригады и предлагает свои строительные/ремонтные/монтажные/отделочные работы.

Заказчик без самопрезентации исполнителя:
Если автор описывает, что ему нужно сделать на объекте и просит откликнуться/написать в лс, но не предлагает свои услуги как исполнитель (нет смысла «я/мы делаем, выполняем, оказываем») — это не целевое сообщение → type = "мусор".
Типично: «нужно смонтировать», «надо сделать», «срочно нужно …», короткий запрос работ без блока о своей бригаде/мастерстве — при отсутствии явных маркеров исполнителя ниже → "мусор".

Признаки "предложение услуги":
- я мастер
- выполняю / делаю / оказываю услуги
- ищу заказ / ищу объект (именно поиск заказа исполнителем, а не набор людей на работу)
- возьму объем
- свободен / свободна бригада (о своей готовности к заказам; не путать с вопросом к аудитории «кто свободен?» / «есть кто на объект?» — такие вопросы без описания своей бригады как исполнителя → "мусор")
- мы бригада
- работаем по ремонту, отделке, монтажу, электрике, сантехнике, кровле, фасадам, бетону, сварке, покраске

Найм и набор персонала (всегда "мусор", даже если тема стройки):
- нужны / ищем / требуются (набор людей)
- нужен мастер / нужна бригада / нужны люди
- требуется помощник / требуется N человек / требуются специалисты списком
- сочетание «требуются/нужны» + число людей или «бригада 10-15 человек» и оплата/объём как условия найма
- есть работа / подработка
- смена / выход сегодня / завтра
- оплата за смену
- адрес объекта и время выхода как условия найма
- ищу исполнителя
- вопрос к аудитории «кто свободен?», «есть кто свободен?», «есть кто на объект?» без дальнейшего описания своих услуг как исполнителя

"мусор" выбирай во всех остальных случаях.

Всегда "мусор", если автор ищет работников или предлагает работу/подработку:
- нужны / ищем / требуются
- нужен мастер / нужна бригада / нужны люди
- требуется N человек
- есть работа / подработка
- смена / выход сегодня / завтра
- оплата за смену
- адрес объекта и время выхода
- ищу исполнителя
- кто свободен (как вопрос к найму; не путать с «свободен, возьму объём» про себя)

Строительная тематика сама по себе НЕ делает сообщение целевым.
Если есть признаки найма — это "мусор".
При сомнении — "мусор".

Если type = "мусор":
reason заполни кратко.
Все остальные строки и числа = null.
Все массивы = [].
contact_info = все null.

Если type = "предложение услуги":
заполни поля только из текста сообщения.
Не выдумывай данные.

Нормализация:
3к → 3000
150тр → 150000
мск → Москва
спб → Санкт-Петербург
болгарка → УШМ
перф → перфоратор
бригадой → бригада
вдвоём → работа с напарником
tg / telegram / телега → telegram
whatsapp / ватсап / вотсап → whtsp

specialities:
только из списка SPECIALITIES, максимум 3.
